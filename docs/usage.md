# pictag の使い方

README の「主な特徴」の詳しい説明と、画面の操作を話題ごとにまとめています。起動方法と出力は [README](../README.md) を見てください。

## 表と段落
- Flask ベースの軽量 Web アプリ。画像ディレクトリを読み込み、サムネイルを自動で作ります
- 段落は、固定の picture / action と、人物などの段落（新規は girl と guy。dog などは必要なときに足す）です。空の段落は書き出しません
- 確定タグ（picture は place / characters / vibes / view / extra、人物などは looks / clothes / body）は、空の欄にも薄く出ます。欄には入力欄と同じく、キーの名前の下に値を出します（キーの無い文や確定タグに無いキーの行は「その他:」の下。action と else は行をそのまま）。characters は入力のある人物の段落から自動で作ります（1 girl + 2 guys (guy A, guy B)）。同じ人物の段落を足すと A, B, … が付き、同じ種類どうしが隣に並びます。ただし、その行で入力のある段落が1つだけの種類は、A, B を除いた名前で書き出します（guy A だけに入力がある行は、キャプションの段落名が guy:、characters は 1 guy。表の列の名前は guy A のまま）
- else という名前の段落は、人物でない物の置き場です（`dog: brown fur`・`cat: black` のようにキーで書き分ける）。物ごとに文で書くときは、`mirror:` のあとで改行して文を並べてかまいません（欄を離れると `mirror: face reflects on mirror. ball reflects on mirror.` の1行にまとまる）。確定タグは無く、👀 の POV のボタンも出ません。characters には人物として数えず、行のキーを数なしで足します（1 girl + dog + cat）
- 段落の列は、見出しの右端の ◀ で細く畳めます（▶ で元の幅に戻す）。畳んだ列には入力のある行に ● が出て、欄をクリックすると列が開いて編集が始まります（畳んだ状態はプロジェクトごとにブラウザが覚えます）。畳む・開くと行の高さが変わりますが、見えていた最初の画像（畳んだ欄をクリックしたときはその行）は、押す前と同じ位置に見せ直します
- 行ごとに、キャプションのトークン数と上限（507）を token の欄に表示します。数字にマウスを載せると、書き出す文面が見えます
- サムネイルは picture の欄の高さ（キーの名前の行とボタン。値の行の分では大きくしない）に合わせた正方形です。ファイル名はサムネイルにマウスを載せると見えます。見出しの ▶ で 1.5 倍に広げ、◀ で戻せます（増えた幅は picture より右の畳んでいない列から少しずつ借ります。広げた状態はプロジェクトごとにブラウザが覚えます）

| 操作 | 内容 |
|---|---|
| 既存プロジェクト / 読み込み | プロジェクトを開く（読み込みは画像フォルダのパスを入力） |
| 参照… | このPCでフォルダを選ぶ窓を開き、選んだフォルダをそのまま読み込む（LAN の別の機器から開いたときは使えないので、パスを入力する） |
| 段落を追加 / 見出しをダブルクリック / 見出しの × | 人物などの段落の追加 / 改名 / 表から外す（picture と action は固定。else と名付けると人物でない物の段落になる） |
| 見出しの ◀ / ▶ | 段落の列を細く畳む / 元の幅に戻す（畳んだ列は入力のある行に ●。欄をクリックすると列を開いて編集を始める。プロジェクトごとにブラウザが覚える） |
| action の見出しの ⇄ | action の文の動詞の形（is doing: `girl is sitting.` / does: `girl sits.`）を全部の行で数え、多い方にそろえる。窓に「変える前 → 変えた後」の一覧が出て、チェックしたものだけ入れる（直す文は初めからチェック、迷う文（and の後ろが離れた動詞・is going to・辞書に無い動詞・hand などの体の部分の語）はチェック無し）。s の無い現在形（`she sit.`）も does の形として数え、そろえるときに s を付ける。has などの状態の動詞は数えない。同じ数なら、どちらにそろえるかを窓で聞く（ボタンで選ぶと、その形への一覧が出る）。削除済みの行は数えない。保存はまだ（📍 の時刻にも数えない） |
| サムネイルをクリック / マウスを載せる | 元画像を表示 / ファイル名を見る |
| サムネイルの見出しの ▶ / ◀ | サムネイルを 1.5 倍に広げる / 元の大きさに戻す（増えた幅は picture より右の畳んでいない列から同じだけずつ借りる。プロジェクトごとにブラウザが覚える） |
| 削除済み画像を表示 / 削除済みを消す | 元フォルダから消えた画像の行を表示するか / 行を表から完全に消す（あわせて保存） |
| 📍（2段目の右端） | 続きへ: 最後に書き換えた行を、列の見出しのすぐ下に見せる（行先はマウスを載せると見える）。数えるのは、その行の欄の書き換え・Qwen の下書き・1行だけに押した表示のボタン（一括入力・キーを移す・選んだ複数行へのボタンは数えない）。行ごとの書き換えた時刻は保存で table.json に書く。その行が絞り込みなどで隠れていれば、知らせるだけ。書き換えた行が無いうちは押せない |
| 保存（Ctrl+S） | 表とキャプション txt を書き出す。保存ボタンはいつも右上の端（メッセージはその左に出て、どれも出た時刻が付く） |

## view のボタン
- view はボタンでも選べます。🎥 は向き（🧍 front・🚶 side・🔙 behind）、高さ（🦅 above・👁️ eye level・🐛 below）、ショットの大きさ（🔍 close-up・🖼️ portrait・👕 medium shot・🏞️ long shot）の組から1つずつ。👀 は 👥 third-person（先頭）か人物ごとの POV（👧 A のように絵文字と A, B。女性はピンク、男性は青）。A, B ごとのボタンは、その行で入力のある段落が2つ以上の種類だけで、ほかは種類の名前（guy POV）のボタンが1つです（キャプションの段落名とそろう）。各組の ☓ で外します。絵文字だけのボタンは ☓ と同じ幅で、語句はボタンにマウスを載せると見えます。close-up は後ろに対象を書けます（close-up face）。ボタンでは close-up として扱い、ほかの大きさを押すと置き換わります（対象は消えます）

## 入力欄と候補
- 入力欄で打つと、辞書から fzf のようなあいまい検索で候補が出ます。キーの後ろでは語句を、action などのキーの無い文では単語を補完します。語句の候補は、同じ種類の段落で使ったものだけです（girl と woman、guy・man・boy はそれぞれまとめ、dog などは種類ごと）。キーの無い文では、語の後にスペースを2つ続けると、打たなくても単語の候補が出ます（3つ目でしまいます）。キーの後ろ（キーの欄・一括入力も）でも、語の後にスペースを2つ続けると、カンマを打ったときと同じ次の語句の候補が出ます（3つ目でもしまいません）
- 入力欄を離れると、カンマと空白を整えます（`a,, b`・`a,b`・`a , b` → `a, b`。語の間に続いた空白は1つに）。行頭で重なった同じキーは1つにまとめます（`looks: looks :` → `looks:`）。action のキーの無い文は「.」で終えます（`, .` と行末のカンマ → `.`）。「.」の前の空白は消し（`sits .` → `sits.`。`.5` のような数は残す）、続いた「.」は1つにします（`..`・`...` → `.`。文の間の `. ` は残す）。「その他」の欄で、値の無いキーの行（`mirror:`）の次からのキーの無い行は、空行か次のキーの行まで、そのキーの行に空白でつなぎます（`body:` の次の行なら、確定タグの body の欄へ）
- 書き出しでは、文（`.`・`!`・`?` で終わる語句）は末尾の語でまとめず、空白でつなぎます（`mirror: a., b.` → `mirror: a. b.`）。文の終わりのすぐ後ろに語が続いていれば、空白を入れます（`mirror.ball` → `mirror. ball`。`e.g.` や `1.5` は変えない）。入力はそのままです
- 打っている欄（入力欄と一括入力の欄）では、スペースを薄い ␣、改行を薄い ↵ で見せます。印は見た目だけで、文字には入りません
- キャプションや辞書に入る欄（表の入力欄・一括入力・キーを移す・段落の追加と改名・共用辞書の足す語句と改名）は英字だけです。打ったそばから、全角の英数字・記号・空白は半角に、アクセントは外し（`é` → `e`）、「、」「。」と曲がった引用符・ダッシュは `,` `.` `'` `"` `-` に直します。かな・漢字・絵文字などは消して、上の帯に「英字以外は入れられません（○○ を外しました）」と出します。IME の変換中はそのままで、確定したときに直します

| 操作 | 内容 |
|---|---|
| 入力欄をクリック | その欄を編集する。確定タグのある段落は、キーの名前の下にキーごとの欄が並ぶ（値だけを書く。語句はカンマか改行で区切る）。最後の「その他」の欄には、キーの無い文と、確定タグに無いキーの行（`キー: 語句, 語句`）を書く（確定タグのキーの行を書いても、確定するとそのキーにまとまる）。picture は extra に書けるので「その他」の欄が無い（前に書いたほかの行があるときだけ出る）。action と else は1つの欄に、1行に `キー: 語句, 語句` かキーなしの文。最初の値の無いキーの欄から始まる。欄を移っても閉じない（キーの名前をクリックすると、その欄へ）。Esc か入力欄の外をクリックで確定（値の無いキーは保存しない。キーの同じ語句は1つにし、カンマと空白、重なったキーを整え、action の文は「.」で終える）。編集する行は選択状態になる。picture の欄は文字の部分のクリックで開く |
| 候補 | ↑↓で選び、Tab か Enter で確定（Enter は打ちかけがあるか↑↓で選んだときだけ。それ以外は改行）。一番下で ↓ を押すと、候補を閉じて下の行へ動く。語句の候補は同じ種類の段落のものだけ（女性・男性はそれぞれまとめる）。キーのある行で語句を選ぶと、行末なら後ろに `, ` が付き、行の途中ならカンマで区切る（カンマのすぐ後ろなら前に空白も入る）。行頭の「キー: 語句」の候補に、その欄にもう入っている語句は出ない（「その他」の欄で確定タグの `キー:` を選ぶとそのキーの欄へ移り、`キー: 語句` はそのキーの欄に足す）。範囲を選んだ状態で候補を選ぶと、選んだ文字と置き換える（選んだ語句は無いものとして候補を出すので、1つだけのグループの相手とも入れ替えられる）。キーの無い文では、語の後にスペース2つで単語の候補を出し、3つ目でしまう（選ぶと2つのスペースは1つになる）。キーのある行では、語の後にスペース2つで次の語句の候補を出す（カンマの後ろと同じで、3つ目でもしまわない。選ぶと続いたスペースは `, ` になる）。単語を選ぶと、行末なら後ろに `, ` が付く（文を続けるときはカンマの前で打つ。行末のカンマは欄を離れると消え、action の文では「.」になる）。後ろに語が続く所では空白1つで分ける |

## 辞書と共用辞書
- 辞書は全プロジェクトの入力から作ります。新しい語句は使った時点で入り、どの画像からも消えると消えます。「共用辞書に入れる」で今の辞書を共用辞書に入れると、使われなくなっても候補に残ります
- 上の「共用辞書」タブで共用辞書を管理できます。一覧は「キー: 語句」で1行（段落をまたいでまとめる）で、登録・削除・改名（開いているプロジェクトの入力も置き換えられる）ができます
- 「1つだけ」のグループ: 同じキーの語句（looks の standing / sitting / lying など）を、1枚の画像の1段落に1つだけ置けるようにします。1つ入っていれば同じグループの語句は候補に出ず、一括入力でも足さず、ぶつかっている行には ⚠ が付きます

| 操作 | 内容 |
|---|---|
| 共用辞書に入れる | 今使っている語句・単語を共用辞書に入れる |
| キーを移す（「共用辞書に入れる」の右） | 段落 → 移す元のキー → 語句（その段落のそのキーで使っている語句が候補に出る。カンマで区切れば何個でも）→ 移す先のキーを選び「移す」。A, B の付いた段落（girl A・girl B）もまとめて、開いているプロジェクトの全行（削除済みも）と共用辞書のその段落の語句を移す（例: girl の looks の black ponytail hair を body へ）。移す先にもうある行は、移す元から消すだけ。ほかのプロジェクトの入力は変えない。保存はまだ（共用辞書はすぐ変わる） |
| 画像 / 共用辞書（上のタブ） | 画面を切り替える（プロジェクトを開く前でも共用辞書は使える） |
| 共用辞書: 絞り込み | 語句の文字、キー、共用辞書にあるか で一覧を絞り込む |
| 共用辞書: 行をクリック | 行を選ぶ・外す（Shift: 最後にクリックした行からの範囲を足す）。見出しのチェックで表示中をすべて選ぶ |
| 共用辞書: 共用辞書に入れる / 1つだけのグループにする / グループから外す | 選んだ行をまとめて共用辞書に入れる / 同じキーの語句をグループにする（入っているグループがあれば、それとまとめる）/ グループから外す |
| 共用辞書: 共用辞書から消す | 1秒長押しで、選んだ語句を共用辞書から消す（入力はそのまま。使っている語句は一覧に残る） |
| 共用辞書: 改名 | 行の語句の名前を変える（Enter で決定、Esc か欄の外でやめる）。チェックが入っていれば、開いているプロジェクトの入力も置き換える（保存はまだ。他のプロジェクトは変えない） |
| 共用辞書: 共用辞書に足す | 段落 → キー → 語句 で、まだ使っていない語句を足す |

## 一括入力とマーク
- 複数の行を選んで、同じ語句をまとめて足す・消すことができます
- マーキング（作業用の印。キャプションには書き出しません）: 排他の A〜H（1行に1つ）と、複数可の ★●▲■◆♥♣♠（どちらも手で付ける）、単語の ①〜⑯（①〜⑧ と ⑨〜⑯ の 2 列）の 4 列 × 8 個。単語の ①〜⑯ は、帯の「単語」で番号ごとに語句（段落・キー・語句。例: girl / looks / smile）を決めておくと、その語句に合う語句のある行に付きます（A, B の付いた段落も見る。入力が変われば付き直す。行の ①〜⑯ を押すと、その語句を入れる。下の表）。語句はカンマで区切った1つずつと比べ、文末の「.」は外して比べます。`*` は何文字でも（`*hair` は black hair・long hair、`*girl spread arms*` は girl spread arms wildly にも合う）。action など確定タグの無い段落は「（キーなし）」で文に合わせます。語句の設定はプロジェクトごとで、保存で書き出します。中では番号（排他・複数は 0〜7、単語は 0〜15）で持ち、見せる記号は marks.py の表で決めます（記号を差し替えても、保存したマークはそのまま）。マークで絞り込み、「表示中を選択」して一括入力する、といった使い方ができます

| 操作 | 内容 |
|---|---|
| token の欄をクリック | 行を選ぶ（Ctrl: 足し引き、Shift: 最後にクリックした行からの範囲） |
| 一括入力の 追加 / 削除 | 行を選ぶと2段目の帯の右端に2段で出る（上に段落・キー、下に語句と 選択行に追加 / 選択行から削除）。段落 → キー（段落の確定タグなど）→ 語句（そのキーの候補が出る）の順に選び、選んだ行にまとめて足す・消す。同じグループの別の語句がある行には足さない。選んでいないときも場所は取ってあるので、行を選んでも帯の高さは変わらない（表がずれない。窓の幅 1440px 以上なら1段に収まる） |
| 選択解除（3段目の帯、表示中を選択の隣。行を選んでいる間だけ） | 1秒長押しで、選択を解除する |
| マークのボタン | A〜H を付ける・外す / ★●▲■◆♥♣♠ を付け外し（選択中の行の中で押すと選択中の全行）。右の2列の ①〜⑯ は単語のマーク（入力から付く）。押すと、その番号の語句を行に入れる。`*` を含む語句は、合う語句のうち件数が最も多いもの（同数なら候補の一覧で上）。girl A・girl B があれば、その行で入力のある方が1つならそれ、ほかは表で先の方。選択中の行の中で押すと選択中の全行に入れる。付いている行と、同じグループの別の語句がある行には入れない。マウスを載せると設定（段落 / キー / 語句）だけ見える |
| 帯の「単語」の ①〜⑯ を右クリック | その番号の語句を決める欄を開く: 段落（A, B を除いた名前）→ キー（キーなしは文）→ 語句（その段落のそのキーで使っている語句が候補に出る。文は「.」を外して出す）を選んで「決める」、「外す」で設定をやめる（Esc か欄の外で閉じる）。決めた語句はボタンにマウスを載せると見える（設定の無い番号は薄い）。保存はまだ |
| 絞り込みのボタン（3段目の帯）/ 表示中を選択（Ctrl+A） | 排他・複数・単語の段ごとに2段。上の段は左端の ☓ と記号のボタン、下の段は記号の真下の ☓。記号を押すとその印の行だけを出し、もう一度押すと外す。いくつ押しても、押した印のどれかがある行を出す。☓ はその印の無い行（左端の ☓ はその段の印が1つも無い行）で、ほかのボタンと一緒に押すと全部に掛かる（例: ① と ⑧ の下の ☓ で、① があって ⑧ の無い行）。単語の ①〜⑯ と下の ☓ は、語句を決めていないものは押しても絞り込まない（右クリックで決める）/ 見えている行をすべて選ぶ |
| A〜H をクリア / ★〜♠ をクリア（3段目の帯の右端） | 1秒長押しで、全行のその列のマークを消す |

## hint と preview
- 画像フォルダに画像と同じ名前の .txt があれば、右端の hint 列に全文を出します（読むだけ。保存やキャプションには影響しません）。右上の － でその画像の hint を畳めます（畳んだ状態はプロジェクトごとにブラウザが覚えます）
- hint が無ければ、同じ列に preview（書き出すキャプションの全文）を出します。hint があれば、列の見出しの hint / preview で切り替えます（どちらを出すかはプロジェクトごとにブラウザが覚えます）。preview は欄を書き換えるとすぐ変わります

| 操作 | 内容 |
|---|---|
| hint / preview をクリック | 全体を選択（そのままコピーできる） |
| hint の － / ＋ hint | その画像の hint を畳む / 開く |

## qwen 版（Qwen で下書き）
Qwen で下書きする qwen 版は `uv run python app.py --qwen` で起動します。ComfyUI は先に自分で起動しておきます（既定の宛先は `http://127.0.0.1:8189`。変えるときは `--comfyui-url http://…`）。pictag は ComfyUI の起動・停止はせず、pictag 用のノードのつながりを送って答えを受け取るだけです（保存してあるワークフローや設定には触りません）。送った画像の写しは ComfyUI の `input/pictag/` に置きます（同じ画像は上書き）。

- qwen 版（`--qwen` で起動）では、token とマークの間の細い列（上から 🤖・🔖・🔄・🎲）で、その行の空の欄を Qwen に下書きさせられます（ComfyUI の TextGenerate。モデルは Krea2 のテキストエンコーダーと同じ Qwen3-VL-4B）。見本として、空でないキャプションを16個渡します。🤖 は上にある行から近い順に、🔖 は同じマークの行（単語の ①〜⑯ と ★●▲■◆♥♣♠ の両方を共有する行 → 単語だけ・★●▲■◆♥♣♠ だけを共有する行を同じ数ずつ → 単語を共有する行の残り → ★●▲■◆♥♣♠ を共有する行の残り → A〜H が同じ行）を先に、足りない分はランダムに、🎲 はほかの行全部からランダムに選びます（ランダムは押すたびに選び直す）。見本が16個に満たないときは、ある分（0でもよい）と、足りない分を公開の例（映画の有名な場面 10 個。`public_samples.py`）からランダムに足して渡します（公開の例は頼む文から遠い前の方に置き、action の文はプロジェクトで多い方の動詞の形に直して渡す）。その行に何か書いてあれば、それ（前に Qwen が入れて、そのあと直していないものは除く）をひな形に入れて渡し、書いてあるものは変えずに空いている所を埋めるよう頼みます（4つのボタンのどれでも。何も書いていなければ渡しません）。人物などの段落に書いてあれば、characters（`1 girl` など）も入れて渡し、空の人物などの段落は渡しません。あわせて頼む文の直前に、誰がいるかと、その人物を指す語（女性は she・her、男性は he・his・him）を1文で伝えます（`The characters in this image: 1 girl. Use these words for them: girl, she, her.`）。見た目で男女を取り違えやすい人物は、その人物の段落に一言（`looks: smile` など）書いてから押してください。指示文では、行動（していること・姿勢（`girl is standing.`）・関わり）だけを action に、表情・視線・見た目・服は人物の段落に書くよう求めます（ただし、見本の書き方の方が強く効きます）。ひな形の action の文の例は、プロジェクトの action の文で多い方の動詞の形にします（does の形なら `boy sits.`、is doing の形か同じ数なら `boy is sitting.`）。値のあるキーと、文のある段落は変えません。ただし 🔄 は、🔖 と同じ見本で、答えにあるキーと文を入力があっても置き換えます（答えに無いキー・段落は残します。単語のマーク（①など）に当たる語句が答えに無く、マークが外れるときは、押す前の語句を足し直します）。Qwen がたまに返す `none`・`nan`・`nothing`・`n/a`・`not applicable`・`unknown`（ごくまれに `non presented`）と、「無い」を言っているだけの語句（`no extra elements`・`no other details`・`view: no specific view` のように、no のあとにあいまいな語と、物の名前かそのキーの名前が続くもの）は、タグが無いものとして入れません（大文字・小文字と、`(none)` のような前後の括弧は問いません）。`no shoes`・`no glasses` のような見て分かる「無い」は入れます。押し直すと、前に Qwen が入れて、そのあと直していない欄だけを新しい答えで置き換えます（自分で書いた・直したものは残ります）。Qwen の答えは、右端の列の hint_by_qwen でそのまま見られます
