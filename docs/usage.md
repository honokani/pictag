# pictag の使い方

README の「主な特徴」の詳しい説明と、画面の操作を話題ごとにまとめています。起動方法と出力は [README](../README.md) を見てください。

## 表と段落
- Flask ベースの軽量 Web アプリ。画像ディレクトリを読み込み、サムネイルを自動で作ります
- 段落は、固定の picture / action と、人物などの段落（新規は girl と guy。dog などは必要なときに足す）です。空の段落は書き出しません
- 確定タグ（picture は place / characters / vibes / view / extra、人物などは looks / clothes / body）は、空の欄にも薄く出ます。characters は入力のある人物の段落から自動で作ります（1 girl + 2 guys (guy A, guy B)）。同じ人物の段落を足すと A, B, … が付き、同じ種類どうしが隣に並びます
- else という名前の段落は、人物でない物の置き場です（`dog: brown fur`・`cat: black` のようにキーで書き分ける）。確定タグは無く、👀 の POV のボタンも出ません。characters には人物として数えず、行のキーを数なしで足します（1 girl + dog + cat）
- 段落の列は、見出しの右端の ◀ で細く畳めます（▶ で元の幅に戻す）。畳んだ列には入力のある行に ● が出て、欄をクリックすると列が開いて編集が始まります（畳んだ状態はプロジェクトごとにブラウザが覚えます）
- 行ごとに、キャプションのトークン数と上限（507）を token の欄に表示します。数字にマウスを載せると、書き出す文面が見えます
- サムネイルは picture の欄の高さに合わせた正方形です。ファイル名はサムネイルにマウスを載せると見えます。見出しの ▶ で 1.5 倍に広げ、◀ で戻せます（増えた幅は picture より右の畳んでいない列から少しずつ借ります。広げた状態はプロジェクトごとにブラウザが覚えます）

| 操作 | 内容 |
|---|---|
| 既存プロジェクト / 読み込み | プロジェクトを開く（読み込みは画像フォルダのパスを入力） |
| 参照… | このPCでフォルダを選ぶ窓を開き、選んだフォルダをそのまま読み込む（LAN の別の機器から開いたときは使えないので、パスを入力する） |
| 段落を追加 / 見出しをダブルクリック / 見出しの × | 人物などの段落の追加 / 改名 / 表から外す（picture と action は固定。else と名付けると人物でない物の段落になる） |
| 見出しの ◀ / ▶ | 段落の列を細く畳む / 元の幅に戻す（畳んだ列は入力のある行に ●。欄をクリックすると列を開いて編集を始める。プロジェクトごとにブラウザが覚える） |
| サムネイルをクリック / マウスを載せる | 元画像を表示 / ファイル名を見る |
| サムネイルの見出しの ▶ / ◀ | サムネイルを 1.5 倍に広げる / 元の大きさに戻す（増えた幅は picture より右の畳んでいない列から同じだけずつ借りる。プロジェクトごとにブラウザが覚える） |
| 削除済み画像を表示 / 削除済みを完全削除 | 元フォルダから消えた画像の行を表示するか / 行を消す（あわせて保存） |
| 保存（Ctrl+S） | 表とキャプション txt を書き出す。保存ボタンはいつも右上の端（メッセージはその左に出て、どれも出た時刻が付く） |

## view のボタン
- view はボタンでも選べます。🎥 は向き（🧍 front・🚶 side・🔙 behind）、高さ（🦅 above・👁️ eye level・🐛 below）、ショットの大きさ（🔍 close-up・🖼️ portrait・👕 medium shot・🏞️ long shot）の組から1つずつ。👀 は 👥 third-person（先頭）か人物ごとの POV（👧 A のように絵文字と A, B。女性はピンク、男性は青）。各組の ☓ で外します。絵文字だけのボタンは ☓ と同じ幅で、語句はボタンにマウスを載せると見えます。close-up は後ろに対象を書けます（close-up face）。ボタンでは close-up として扱い、ほかの大きさを押すと置き換わります（対象は消えます）

## 入力欄と候補
- 入力欄で打つと、辞書から fzf のようなあいまい検索で候補が出ます。キーの後ろでは語句を、action などのキーの無い文では単語を補完します。語句の候補は、同じ種類の段落で使ったものだけです（girl と woman、guy・man・boy はそれぞれまとめ、dog などは種類ごと）。キーの無い文では、語の後にスペースを2つ続けると、打たなくても単語の候補が出ます（3つ目でしまいます）
- 入力欄を離れると、カンマと空白を整えます（`a,, b`・`a,b`・`a , b` → `a, b`。語の間に続いた空白は1つに）。行頭で重なった同じキーは1つにまとめます（`looks: looks :` → `looks:`）。action のキーの無い文は「.」で終えます（`, .` と行末のカンマ → `.`）
- 打っている欄（入力欄と一括入力の欄）では、スペースを薄い ␣、改行を薄い ↵ で見せます。印は見た目だけで、文字には入りません

| 操作 | 内容 |
|---|---|
| 入力欄をクリック | その欄を編集する。確定タグのキーが並んだ状態で始まる。1行に `キー: 語句, 語句`（キーなしの文も可）。Esc か欄の外をクリックで確定（値の無いキーは保存しない。カンマと空白、重なったキーを整え、action の文は「.」で終える）。編集する行は選択状態になる。picture の欄は文字の部分のクリックで開く |
| 候補 | ↑↓で選び、Tab か Enter で確定（Enter は打ちかけがあるか↑↓で選んだときだけ。それ以外は改行）。一番下で ↓ を押すと、候補を閉じて下の行へ動く。語句の候補は同じ種類の段落のものだけ（女性・男性はそれぞれまとめる）。キーのある行で語句を選ぶと、行末なら後ろに `, ` が付き、行の途中ならカンマで区切る（カンマのすぐ後ろなら前に空白も入る）。行頭の「キー: 語句」の候補に、その欄にもう入っている語句は出ない。範囲を選んだ状態で候補を選ぶと、選んだ文字と置き換える（選んだ語句は無いものとして候補を出すので、1つだけのグループの相手とも入れ替えられる）。キーの無い文では、語の後にスペース2つで単語の候補を出し、3つ目でしまう（選ぶと2つのスペースは1つになる）。単語を選ぶと、行末なら後ろに `, ` が付く（文を続けるときはカンマの前で打つ。行末のカンマは欄を離れると消え、action の文では「.」になる）。後ろに語が続く所では空白1つで分ける |

## 辞書と共用辞書
- 辞書は全プロジェクトの入力から作ります。新しい語句は使った時点で入り、どの画像からも消えると消えます。「共用辞書に入れる」で今の辞書を共用辞書に入れると、使われなくなっても候補に残ります
- 上の「共用辞書」タブで共用辞書を管理できます。一覧は「キー: 語句」で1行（段落をまたいでまとめる）で、登録・削除・改名（開いているプロジェクトの入力も置き換えられる）ができます
- 「1つだけ」のグループ: 同じキーの語句（looks の standing / sitting / lying など）を、1枚の画像の1段落に1つだけ置けるようにします。1つ入っていれば同じグループの語句は候補に出ず、一括入力でも足さず、ぶつかっている行には ⚠ が付きます

| 操作 | 内容 |
|---|---|
| 共用辞書に入れる | 今使っている語句・単語を共用辞書に入れる |
| 画像 / 共用辞書（上のタブ） | 画面を切り替える（プロジェクトを開く前でも共用辞書は使える） |
| 共用辞書: 絞り込み | 語句の文字、キー、共用辞書にあるか で一覧を絞り込む |
| 共用辞書: 行をクリック | 行を選ぶ・外す（Shift: 最後にクリックした行からの範囲を足す）。見出しのチェックで表示中をすべて選ぶ |
| 共用辞書: 共用辞書に入れる / 1つだけのグループにする / グループから外す | 選んだ行をまとめて共用辞書に入れる / 同じキーの語句をグループにする（入っているグループがあれば、それとまとめる）/ グループから外す |
| 共用辞書: 共用辞書から消す | 1秒長押しで、選んだ語句を共用辞書から消す（入力はそのまま。使っている語句は一覧に残る） |
| 共用辞書: 改名 | 行の語句の名前を変える（Enter で決定、Esc か欄の外でやめる）。チェックが入っていれば、開いているプロジェクトの入力も置き換える（保存はまだ。他のプロジェクトは変えない） |
| 共用辞書: 共用辞書に足す | 段落 → キー → 語句 で、まだ使っていない語句を足す |

## 一括入力とマーク
- 複数の行を選んで、同じ語句をまとめて足す・消すことができます
- マーキング（作業用の印。キャプションには書き出しません）: 排他の A〜D（1行に1つ）と、複数可の ★●▲■。マークで絞り込み、「表示中をすべて選択」して一括入力する、といった使い方ができます

| 操作 | 内容 |
|---|---|
| token の欄をクリック | 行を選ぶ（Ctrl: 足し引き、Shift: 最後にクリックした行からの範囲） |
| 選択行に追加 / 選択行から削除 | 行を選ぶと2段目に出る。段落 → キー（段落の確定タグなど）→ 語句（そのキーの候補が出る）の順に選び、選んだ行にまとめて足す・消す。同じグループの別の語句がある行には足さない |
| 選択解除 | 1秒長押しで、選択を解除する |
| マークのボタン / キー 1〜4・0・5〜8 | A〜D を付ける・外す / ★●▲■ を付け外し（選択中の行の中で押すと選択中の全行。キーは入力欄の外で、選択行に） |
| 絞り込み / 表示中をすべて選択（Ctrl+A） | マークで行を絞り込む / 見えている行をすべて選ぶ |
| A〜D をクリア / ★●▲■ をクリア | 1秒長押しで、全行のその列のマークを消す |

## hint と preview
- 画像フォルダに画像と同じ名前の .txt があれば、右端の hint 列に全文を出します（読むだけ。保存やキャプションには影響しません）。右上の － でその画像の hint を畳めます（畳んだ状態はプロジェクトごとにブラウザが覚えます）
- hint が無ければ、同じ列に preview（書き出すキャプションの全文）を出します。hint があれば、列の見出しの hint / preview で切り替えます（どちらを出すかはプロジェクトごとにブラウザが覚えます）。preview は欄を書き換えるとすぐ変わります

| 操作 | 内容 |
|---|---|
| hint / preview をクリック | 全体を選択（そのままコピーできる） |
| hint の － / ＋ hint | その画像の hint を畳む / 開く |
| 列の見出しの hint / preview / hint_by_qwen | 右端の列に hint、preview（書き出すキャプション）、hint_by_qwen（Qwen の答え。qwen 版だけ）のどれを出すかを切り替える（hint が無いときは hint のボタンは出ない。preview しか出せなければ文字だけ）。切り替えると行の高さが変わるので、見えていた最初の画像（上が切れていない行）を、押す前と同じ位置に見せ直す |

## qwen 版（Qwen で下書き）
Qwen で下書きする qwen 版は `uv run python app.py --qwen` で起動します。ComfyUI は先に自分で起動しておきます（既定の宛先は `http://127.0.0.1:8189`。変えるときは `--comfyui-url http://…`）。pictag は ComfyUI の起動・停止はせず、pictag 用のノードのつながりを送って答えを受け取るだけです（保存してあるワークフローや設定には触りません）。送った画像の写しは ComfyUI の `input/pictag/` に置きます（同じ画像は上書き）。

- qwen 版（`--qwen` で起動）では、token とマークの間の細い列（上から 🤖・🔖・🎲）で、その行の空の欄を Qwen に下書きさせられます（ComfyUI の TextGenerate。モデルは Krea2 のテキストエンコーダーと同じ Qwen3-VL-4B）。見本として、空でないキャプションを10個渡します。🤖 は上にある行から近い順に、🔖 は同じマークの行（A〜D が同じ行 → ★●▲■ を共有する行）を先に、足りない分はランダムに、🎲 はほかの行全部からランダムに選びます（ランダムは押すたびに選び直す）。見本が足りない行は押せません。指示文では、行動（していること・関わり）だけを action に、表情・視線・姿勢・見た目・服は人物の段落に書くよう求めます（ただし、見本の書き方の方が強く効きます）。値のあるキーと、文のある段落は変えません。Qwen がたまに返す `none`・`nan` は、タグが無いものとして入れません。押し直すと、前に Qwen が入れて、そのあと直していない欄だけを新しい答えで置き換えます（自分で書いた・直したものは残ります）。Qwen の答えは、右端の列の hint_by_qwen でそのまま見られます

| 操作 | 内容 |
|---|---|
| 🤖 / 🔖 / 🎲（qwen 版だけ。token の半分の幅の列に、上から縦に積む） | その行の空の欄（値の無いキーと、文の無い段落）を Qwen に下書きさせる。見本（キャプションのある行）は、🤖 が上の10行（近い順。名前の順で似た画像が並ぶ）、🔖 が同じマークの行を先に（A〜D が同じ行 → ★●▲■ を共有する行 → 足りない分はランダム）、🎲 がほかの行からランダムに10行（いろいろな画像の書き方）。ランダムは押すたびに選び直す。見本が足りなければ押せず、理由はマウスを載せると見える。数秒（ComfyUI が初めて Qwen を読むときは数十秒）。書いている間は押した方が ⏳ |
